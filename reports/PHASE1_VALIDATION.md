The real startup script was launched hidden using the following command, after
setting the private `.env` port to 8001 without printing its content:

```powershell
$projectRoot = (Get-Location).Path
$startupScript = Join-Path $projectRoot 'scripts\start-local.ps1'
$runtimeDir = Join-Path $projectRoot '.runtime'
$serverProcess = Start-Process -FilePath (Get-Process -Id $PID).Path -ArgumentList @('-NoProfile', '-File', ('"' + $startupScript + '"')) -WorkingDirectory $projectRoot -WindowStyle Hidden -RedirectStandardOutput (Join-Path $runtimeDir 'server-8001.stdout.log') -RedirectStandardError (Join-Path $runtimeDir 'server-8001.stderr.log') -PassThru
$serverProcess.Id | Set-Content -LiteralPath (Join-Path $runtimeDir 'launcher-8001.pid')
```
