# Demonstration Script

Version: 1.0 · Updated: 2026-10-22 · Status: proposed implementation specification

## Eight-minute project demo target

0:00 explain the production interruption problem. 0:45 register/locate a machine and marked sensor. 1:30 start a held-out replay and show explicit replay label. 2:15 show risk, RUL and evidence with actual measured model version. 3:15 disconnect a required demo sensor and show unavailable status. 4:00 create a reviewed inspection draft; attempt an unauthorized approval and show denial. 5:00 record a sample finding, repair and verification as a separate synthetic scenario. 6:00 show real evaluation report and limitations. 7:00 show model gate/rollback and summarize next pilot steps.

## Challenge mode

Let reviewers choose wrong mapping, duplicate event, stale data, unavailable technician or unreviewed model. Display expected behavior and actual result. Never secretly force a risk score to manufacture a successful model demo. Injected scenarios are clearly tagged synthetic.

## Evidence to prepare

Seed fixture versions; source/split hashes; model artifact ID; actual evaluation report; test run summary; role identities without passwords on screen; audit timeline; known limitations. If the model is not trained, present architecture walkthrough only and state that limitation.
