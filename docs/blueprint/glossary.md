# Glossary — Simple Hinglish

Version: 1.0 · Updated: 2026-10-22 · Status: proposed implementation specification

| Term | Meaning |
|---|---|
| RUL | Machine ke estimated remaining operating cycles |
| Horizon | Kitne aage ke cycles ka failure risk estimate kar rahe hain |
| Calibration | 70% probability wale comparable cases ka observed frequency roughly us probability se match karta hai ya nahi |
| Data drift | Input patterns badal rahe hain; model wrong hone ka proof nahi |
| Model degradation | True outcomes ke comparison mein performance weak hona |
| Idempotency | Same request retry hone par duplicate action na ho |
| Outbox | DB transaction ke saath future event delivery record save karna |
| Tenant | Organization ka isolated data/access scope |
| Abstention / unavailable | Evidence insufficient ho to confident number na dena |
| Feature | Raw history se model ke liye nikala gaya input |
| Leakage | Training/tuning mein future ya test information pahunch jana |
| Censoring | Intervention ya observation end hone se true failure time na milna |
| MCP | Assistant ko controlled application tools dene ka protocol |
| MLOps | Model training, versioning, deployment aur monitoring ka operational process |
| Optimistic concurrency | Expected version match ho tabhi update accept karna |
