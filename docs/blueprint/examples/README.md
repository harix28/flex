# Contract examples

These are illustrative fixtures, not real measurements or seeded database IDs. Replace UUIDs with registered records before submitting to a future API. The one-reading telemetry example demonstrates schema shape; it does not meet a full 21-sensor model requirement. The ingestion semantic validator must enforce the model/asset required-sensor policy separately. `dataset_native` is a placeholder unit until archive documentation is mapped and verified. Never label this value as temperature in °C.

The prediction example intentionally returns unavailable, with null estimates. It is not an achieved model result.
